# 用 Pi 原生工具调用替换自研文本协议

一次性生成与多轮写作助手的底层改为 `@earendil-works/pi-ai` 与 `pi-agent-core`。工作流仍由现有编排层驱动，但每次模型调用走 pi-ai 流式接口，并以强制 `submit_*` 工具交卷；助手会话在主进程创建 Agent，不在渲染进程持有 API Key。旧的“把 JSON/XML 写进正文”协议不再识别。

明确声明 `toolCalling: false` 的生成模型被拒绝；未声明该字段的既有配置仍可尝试。项目会话租约与模型执行租约保留，因为它们约束的是项目写入边界和密钥隔离，不是自研 Agent 的实现细节。用户提示词覆盖仍从 `~/.vela/prompts/` 与项目 `.vela/prompts/` 读取；其中若仍要求纯文本交卷，作者应恢复为内置默认，而不是由软件做协议级迁移。
