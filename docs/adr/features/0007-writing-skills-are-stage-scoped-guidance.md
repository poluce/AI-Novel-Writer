# 功能 ADR 0007：写作技能（Skill）按需调用与自包含约束

- 状态：已取代阶段绑定（现行业务规则）
- 领域：小说创作工作流 / 技能与技法调度

## 背景

阶段绑定曾把 Skill 固定到 planning / drafting / review / refinement，并在工作流启动时冻结进提示词。这与「技能作为工具按需调用、全书底层文风由写作风格统一保证」相悖，也会让各阶段提示词互相污染。

## 决策

**写作 Skill 不再绑定创作阶段，只作为按需工具调用；必须是自包含提示词。**

1. **按需调用**：助手通过唯一工具 `manage_skills`（action: `"load"`）读取 `SKILL.md` 正文后执行。用户输入 `/技能名` 时正文注入该轮消息。
2. **全书底层文风**：由项目设定的 `writingStyle` 统一规范，不靠阶段绑定 Skill。
3. **自包含约束**：Skill 必须是纯净提示词。脚本、hook、相对引用、子代理和工具执行要求不得安装。

## 后果与权衡

* **收益**：工作流提示词不再被冻结 Skill 污染；技能与文风职责分离。
* **代价**：模型必须主动 `manage_skills load`，不会在每个工作流步骤自动带上阶段技法。
