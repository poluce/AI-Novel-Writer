# 功能 ADR 0007：写作技能（Skill）按创作阶段隔离与自包含约束

- 状态：已采纳（现行业务规则，继承 0015）
- 领域：小说创作工作流 / 技能与技法调度

## 背景

在小说创作过程中，不同环节对技法的要求截然不同：构思大纲时需要宏观三幕式与爽点分布；正文起草时需要细节白描与心理动作特写；审稿时需要挑刺排查逻辑漏洞。如果将各种技能一股脑塞进大模型提示词，会导致模型认知混乱、各阶段 prompt 相互冲突打架。

## 决策

**写作 Skill 严格按创作阶段（Stage）进行作用域划分与阶段隔离，且必须严格遵循“自包含提示词”原则。**

1. **按创作阶段绑定与生效**：
   * 划分为“大纲规划”、“正文起草”、“审稿挑错”、“润色修稿”四个阶段；
   * 每个项目在同一阶段最多绑定一个专用 Skill，实现技法的精准匹配与阶段解耦；
2. **工作流启动即冻结（Stage Snapshot Freeze）**：
   * 工作流（如起草、审稿）启动瞬间，根据项目语言冻结所绑定的 Skill 快照，生成期间外部改动绝不影响运行中的任务；
3. **自包含约束（Self-contained Policy）**：
   * 作为小说创作指导的 Skill 必须是纯净自包含的提示词说明（Prompt-only）；
   * 严禁技能包私带未授权的可执行外部脚本或侵入式钩子，保障小说生成管线的安全受控。

## 后果与权衡

* **收益**：各创作环节提示词干净精准，彻底杜绝了技能提示词相互干扰；
* **代价**：不支持单个阶段同时堆叠 5~10 个技能包，要求创作者精选特定技法。
