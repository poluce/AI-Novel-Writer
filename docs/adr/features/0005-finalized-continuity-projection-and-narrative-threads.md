# 功能 ADR 0005：连续性推演严格源自定稿事实，叙事线索计划分层

- 状态：已采纳（现行业务规则，整合 0013 与 0017）
- 领域：长篇小说剧情连续性 / 伏笔线索与人物状态追踪

## 背景

长篇小说（数十万至百万字）极易出现“战力崩塌、人物性格漂移、前文死掉的角色后文复活、伏笔忘记回收”等连续性灾难。若允许 AI 根据未确认的半截草稿或凭空脑补来推断小说事实，会导致前后文推演全面失真。

## 决策

**全书连续性事实与人物状态演化，严格且唯一由“已定稿正文（Finalized Chapters）”及“创作者已确认的结构化事实”重建推演。**

1. **定稿作为唯一推演锚点**：
   * 只有正式完成提交的不可变定稿正文，才能作为人物状态（伤残、死亡、能力晋升、阵营转移）与事件发生的法定证据；临时草稿绝不作为权威事实。
2. **叙事线索（Narrative Threads）计划与识别分层**：
   * **作者规划事实（Plan）**：作者预设的伏笔、暗线、悬念目标章节，是神圣不可侵犯的纲领，AI 扫描绝对不得覆盖作者的人工规划；
   * **AI 识别线索事件（Evidence Events）**：AI 仅在审稿时产出候选证据，必须经作者人工确认后才追加记录为不可变线索事件，折叠更新线索状态。
3. **冲突提醒永不强行改写**：
   * 连续性冲突仅以带引文证据的警告形式呈现，AI 严禁自动篡改蓝图或正文；作者可选择采纳修改，或标记“这是有意安排”获得合规豁免。

## 后果与权衡

* **收益**：彻底杜绝了 AI 凭借幻觉随意编造前文情节导致小说世界观崩塌的致命风险；
* **代价**：对于尚未定稿的大量草稿章节，连续性系统无法将其直接计入全局已发生事实。
