# 功能 ADR 0006：剧情树作为可重建的只读派生快照

- 状态：已采纳（现行业务规则，继承 0014）
- 领域：大纲可视化 / 剧情树派生快照

## 背景

为了让作者直观俯瞰主线、支线与各章节情节的汇聚走向，系统提供了“剧情树（Plot Tree）”可视化视图。若将剧情树本身做成可自由编辑的主数据，极易使图节点与实际的章节蓝图、故事大纲产生脱节，形成“图上写了一套、蓝图又写了一套”的双重事实源混乱。

## 决策

**剧情树唯一定位为由底层权威事实（故事大纲、细纲蓝图、已定稿摘要、叙事线索）推导生成的“只读派生快照”。**

1. **单向派生，严禁反写**：
   * 剧情树仅用于全景浏览、走向复盘与节点定位导航；它不作为事实源，也不参与正文起草提示词，更严禁反向篡改大纲和蓝图；
2. **可随时清空与幂等重建**：
   * 剧情树快照存储于数据库，随时可以安全清空并在事实完备时一键重新生成；
3. **版本失步温和提示**：
   * 当后方大纲或蓝图被修改导致剧情树版本落后时，仅在界面提示“需刷新”，绝不自动触发昂贵的大模型推理。

## 后果与权衡

* **收益**：维护了“大纲与蓝图才是小说剧情真正事实源”的清晰心智，避免了第二套事实源的出现；
* **代价**：创作者无法直接在剧情树节点上随意拖拽节点来直接更改蓝图，必须通过修改蓝图来重新派生树。
